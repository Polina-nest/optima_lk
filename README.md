# ТестовыйЛК — публикация на Timeweb

Пакет подготовлен из переданного `dist.zip` 11 ноября 2026 года.
Сайт состоит из готовых HTML, CSS, JavaScript и тестовых документов.
Публикация выполняется через репозиторий https://github.com/Polina-nest/optima_lk.

## 1. Загрузка в GitHub через браузер

1. Полностью распакуйте `optima-lk-timeweb.zip` на компьютер.
2. Откройте распакованную папку `optima-lk-timeweb`. В ней находятся папка `dist` и этот `README.md`.
3. Откройте https://github.com/Polina-nest/optima_lk под своим аккаунтом.
4. Нажмите **Add file → Upload files**. Если репозиторий пустой, нажмите ссылку **uploading an existing file** на странице первоначальной настройки.
5. Перетащите **папку `dist` целиком** и `README.md` в область загрузки. Папка сайта должна остаться папкой `dist` внутри репозитория.
6. Дождитесь завершения загрузки. В поле комментария можно написать `Подготовка сайта для Timeweb`.
7. Нажмите **Commit changes**. Запомните ветку, в которую добавлены файлы; обычно это `main`.
8. Откройте папку `dist` в GitHub и убедитесь, что в ней есть `index.html`, `quotes.html`, `documents.html` и папки с документами.

Загружайте распакованную папку, а не ZIP: Timeweb должен получить готовые файлы сайта.
В пакете 95 файлов сайта и 1 README. Каждый файл меньше 25 MiB; общее число укладывается в ограничение GitHub на одновременную загрузку 100 файлов.

Если GitHub сообщает об отсутствии прав или защите ветки, сохраните изменения в новой ветке и выберите её в Timeweb. Защиту существующей ветки менять не требуется.

## 2. Настройки Timeweb Cloud

Откройте **App Platform → Создать → Приложение → GitHub** и подключите репозиторий.

| Поле | Значение |
| --- | --- |
| Репозиторий | `Polina-nest/optima_lk` |
| Ветка | Ветка с загруженными файлами, обычно `main` |
| Тип приложения | Frontend / HTML/CSS/JS |
| Директория проекта | `dist` |
| Название | `optima-lk` |

Для HTML/CSS/JS команда сборки, директория сборки и установка зависимостей не требуются: платформа публикует готовые файлы. Укажите именно **директорию проекта** `dist`.

Завершите создание приложения после проверки выбранного типа и стоимости в панели. После успешного развёртывания откройте HTTPS-адрес, выданный Timeweb, и проверьте основные разделы и скачивание документов. Этот адрес можно отправлять пользователям.

## Что подготовлено

- Служебные стили сохранённых страниц встроены в HTML в прежнем порядке. Это уменьшает число файлов и HTTP-запросов. Файлы пользовательских стилей, например `invoices-exact.css`, оставлены отдельно для последующих правок.
- На `index.html` подключена логика акцепта, которая уже использовалась на `quotes.html`.
- 60 ссылок на исходный рабочий кабинет заменены ссылками внутри тестового сайта. Обработчики навигации в заявках сохраняют новые локальные адреса.
- Все 45 PDF, Excel и XML-файлов совпадают с исходным архивом побайтно.
- Проверены локальные ссылки в HTML, синтаксис JavaScript, условия доступности действий, истечение акцепта через 10 минут и правила просмотра PDF/Excel.

Браузерная визуальная проверка в среде подготовки не была доступна. После размещения проверьте внешний вид в своём браузере.

## Особенности тестового кабинета

Это демонстрационная версия без общего серверного хранилища. Изменения статуса акцепта хранятся в браузере конкретного пользователя; они не синхронизируются между компьютерами.

Код сайта не зависит от PuTTY и адреса офисного сервера. Для резервного шрифта используется Google Fonts; если сервис недоступен, браузер использует системный шрифт.
